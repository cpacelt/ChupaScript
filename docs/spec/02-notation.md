# 2. Нотация и конвенции

Раздел задаёт, как читать остальные: что нормативно, как называются правила,
какие термины не переводятся.

## 2.1. Нормативность и идентификаторы

**Нормативность.** Обычный текст нормативен. Блоки `> Пояснение` и все примеры
кода — ненормативны. Противоречие между примером и правилом решается в пользу
правила.

**Обязательность.** ДОЛЖЕН / НЕ ДОЛЖЕН / МОЖЕТ — в смысле RFC 2119.

**Термины ECMA-262** приводятся в оригинале и не переводятся: `Early Error`,
`ToPrimitive`, `code unit`. Продукция грамматики называется своим именем и
набирается моноширинным: `Statement`, `AssignmentExpression`.

**Слово «оператор»** относится только к операторам — `+`, `??`, тернарному.
В русской традиции им переводят и *statement*, но здесь этот смысл закреплён за
`Statement`: «оператор в операторе» не должно быть законной фразой.

**Идентификаторы правил.** Каждое проверяемое утверждение имеет стабильный
идентификатор вида `CS-EE-0007`. Номер не переиспользуется и не меняется никогда:
отменённое правило помечается изъятым, но его номер не занимается другим правилом.
Тест называется по идентификатору, интерпретатор печатает его в ошибке, книга
ссылается на него сноской.

Исключение — грамматика: там идентификатором служит имя продукции. Оно
уникально, стабильно и осмысленно, а сквозная нумерация продукций только мешала
бы при правках.

| Префикс | Что нумерует |
|---|---|
| `CS-CONF-` | инвариант подмножества JavaScript |
| `CS-LEX-` | правило лексики, невыразимое продукцией |
| `CS-EE-` | статическая ошибка (Early Error) |
| `CS-RT-` | правило времени исполнения |
| `CS-LIB-` | встроенное средство |
| `CS-DIV-` | намеренное расхождение с ECMA-262 |

## 2.2. Конвенции изложения

**Код — по-английски, проза — по-русски.** Внутри обратных кавычек: имена
продукций, средств, параметров, ключевых слов. Русских идентификаторов не бывает
нигде. Снаружи — русский текст: «получатель», а не «receiver».

**Ссылка на утверждение — по идентификатору, а не по номеру раздела.** Номер
раздела допустим только там, где речь о разделе целиком. Идентификатор не
меняется никогда, номер раздела меняется при всякой перестройке.

**Раздел о конструкции имеет одну и ту же форму:** продукция, статические
правила, семантика, сужение относительно JavaScript, примеры.

**Неверный пример — дефект.** Примеры ненормативны, но обязаны быть верными:
они извлекаются из документа и прогоняются на V8.

**Всякая сводка справочна.** Нормативно утверждение на своём месте, рядом со
своей конструкцией. Сводка грамматики, перечень сужений и перечень
наследуемого поведения существуют, чтобы увидеть целое; расхождение сводки с
телом есть устаревание копии, а не дефект корректности.

**Непереводимые термины** — закрытый список. Он составляется в фазе 2 вместе с
разделом; до тех пор действует правило из 2.1: термины ECMA-262 приводятся в
оригинале.
