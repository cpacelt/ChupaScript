# Приложение B. Сужения относительно JavaScript

Документ справочный: собственных правил не вводит. Каждое сужение задано либо
составом продукций `lexical.txt` и `syntax.txt` (разделы 1—5), либо статическим
правилом из `rules.json` (раздел 6), либо составом библиотеки (раздел 7); здесь
они сведены в один перечень.

Все перечисленные сужения отвергают часть текстов, принимаемых JavaScript, и не
изменяют значения ни одного принимаемого.

Расхождения — то есть изменения поведения принятых текстов — сюда не входят.
Принятое расхождение одно, оно записано в приложении C (`CS-DIV-0001`).

## 1. Лексика

| Сужение | Что отвергается |
|---|---|
| `IdentifierStart`, `IdentifierPart` только ASCII | имена, содержащие символы `ID_Start` или `ID_Continue` вне ASCII: буквы и цифры других письменностей, диакритические знаки, U+200C, U+200D |
| экранирование в именах не поддерживается | имена, содержащие `UnicodeEscapeSequence` |
| `of` в `ReservedWord` | `of` в качестве имени |
| суффикс `n` отсутствует | литералы BigInt |
| литералы регулярных выражений отсутствуют | `/…/` в позиции выражения |
| `**`, `**=` и побитовые операторы не входят в `Punctuator` | `**`, `**=`, `&`, `\|`, `^`, `~`, `<<`, `>>`, `>>>` и составные присваивания с ними |
| логические присваивания не входят в `Punctuator` | `&&=`, `\|\|=`, `??=` |
| `<!--` не входит в `Comment` | HTML-подобные комментарии |

## 2. Statement и объявления

| Сужение | Что отвергается |
|---|---|
| `Statement` не содержит `VariableStatement` | `var` |
| единственная форма цикла — `ForOfStatement` | `while`, `do…while`, `for ( ; ; )`, `for…in` |
| `Statement` не содержит `SwitchStatement` | `switch` |
| `Statement` не содержит `TryStatement`, `ThrowStatement` | `try`/`catch`/`finally`, `throw` |
| `LabelledStatement` отсутствует | метки, `break label`, `continue label` |
| `Declaration` не содержит `ClassDeclaration` | `class` |
| `Statement` не содержит `DebuggerStatement` | `debugger` |
| пустой `Statement` отсутствует | одиночная `;` |
| ветви `IfStatement` и тело `ForOfStatement` — только `Block` | `if (x) f();`, `for (const a of b) f();` |
| `LexicalBinding` требует `Initializer` | `let x;` |
| `LexicalDeclaration` содержит один связыватель | `let a = 1, b = 2;` |
| `ForOfStatement` требует `LetOrConst` в заголовке | `for (x of items)` с существующим именем |

## 3. Выражения

| Сужение | Что отвергается |
|---|---|
| `Expression` совпадает с `AssignmentExpression` | оператор запятая |
| `AssignmentExpression` не содержит логических присваиваний | `a &&= b`, `a \|\|= b`, `a ??= b`; записывается условным оператором или `if` |
| `UnaryExpression` содержит только `-`, `!`, `typeof` | `delete`, `void`, `~` |
| `UnaryExpression` не содержит альтернативы `+ UnaryExpression` | `+x`; преобразование в число записывается как `Number(x)` |
| `UpdateExpression` отсутствует, а токены `++` и `--` не входят ни в одну другую продукцию | инкремент и декремент в любой форме: `i++`, `++i`, `i--`, `--i`, `a++b`, `a--b`; увеличение записывается как `i = i + 1` |
| `ExponentiationExpression` отсутствует | `a ** b`; возведение в степень — `Math.pow(a, b)` |
| `PrimaryExpression` не содержит `this`, `NewExpression`, `SuperProperty` | `this`, `new`, `super`, `new.target` |
| `RelationalExpression` не содержит `in` и `instanceof` | `k in obj`, `x instanceof C` |
| `PrimaryExpression` не содержит `FunctionExpression` | `function (…) {…}` в позиции выражения, в том числе немедленно вызываемое |
| `async`, `await`, `yield` не участвуют ни в одной продукции | `async`-функции, `await`, `function*`, `yield`, `for await` |
| распространение отсутствует | `...` в вызове, литерале массива и литерале объекта |
| `ElementList` требует выражение между запятыми | пропуски: `[1, , 3]` |
| `PropertyDefinition` содержит только сокращённую запись и `имя : значение` | методы `{ f() {} }`, `get`/`set` в литерале объекта |
| `OptionalChain` не содержит звена `?. Arguments` | `a?.()` |
| `MemberExpression` не содержит `TaggedTemplate` | теговые шаблоны `` tag`…` `` |
| `import` не участвует ни в одной продукции | `import(…)`, `import.meta` |
| завершающая запятая не допускается нигде | `[1, 2, ]`, `{ a: 1, }`, `f(x, )` |

## 4. Функции и образцы

| Сужение | Что отвергается |
|---|---|
| `ArrowParameters` содержит только `Identifier` | образцы и значения по умолчанию в параметрах стрелочной функции |
| `FormalParameter` содержит только `Identifier` и `Identifier = Literal` | образцы и параметр-остаток в параметрах объявленной функции; значение по умолчанию, не являющееся литералом: `function f(a, b = a + 1) {}` |
| целью связывания в образце служит `Identifier` | вложенные образцы: `let { a: { b } } = obj;` |
| образец не содержит `Initializer` и остатка | значения по умолчанию `let { a = 1 } = obj;`, остаток `let { a, ...rest } = obj;` |
| `BindingElementList` требует `Identifier` между запятыми | пропуски: `let [, b] = arr;` |
| `ConciseBody` при теле-блоке разбирается как `Block`, меток нет | `x => { id: x }` — в JavaScript тело с меткой, вычисляющее `undefined` |
| завершающая запятая не допускается нигде | `function f(a, ) {}`, `(a, ) => a`, `let { a, } = o;`, `let [a, ] = xs;` |

## 5. Отвергается и самим JavaScript

Перечисленное ниже сужением в собственном смысле не является: строгий режим,
в котором ChupaLang исполняется всегда, отвергает это и в JavaScript. Строки
приведены, чтобы список конструкций, недопустимых в языке, был полным.

| Конструкция | |
|---|---|
| `with` | запрещён строгим режимом |
| восьмеричная запись `0755` | запрещена строгим режимом |
| `\8`, `\9`, восьмеричные escape-последовательности | запрещены строгим режимом |
| `import`/`export` в форме объявления | недопустимы при цели разбора `Script` |

## 6. Сужения, задаваемые не грамматикой

Продукциями заданы не все сужения. Ниже — те, для которых грамматика
альтернативы не различает, поэтому отвергает их проверка (раздел 5).

Часть из них изъятию не подлежит: без них нарушился бы инвариант раздела 1.
Столбец «Обязательно для» называет нарушаемое требование.

| Правило | Что отвергается | Обязательно для |
|---|---|---|
| CS-EE-0012 | `return` вне тела функции | CS-CONF-0001 — ранняя ошибка JavaScript |
| CS-EE-0013 | `break`, `continue` вне `ForOfStatement` | CS-CONF-0001 — ранняя ошибка JavaScript |
| CS-EE-0006 | непригодная цель присваивания: `1 = x`, `a?.b = 1` | CS-CONF-0001 — ранняя ошибка JavaScript |
| CS-EE-0001 | повторное объявление имени в одной области | CS-CONF-0001 — ранняя ошибка JavaScript |
| CS-EE-0014 | имя `__proto__` в любой форме | CS-CONF-0010 — иначе разошлось бы поведение литерала объекта |
| CS-EE-0002 | обращение к имени до его объявления | — |
| CS-EE-0003 | присваивание имени, объявленному через `const` | — |
| CS-EE-0004 | `undefined`, `NaN`, `Infinity` в позиции объявления или цели присваивания | — |
| CS-EE-0007 | `ArrowFunction` не непосредственно аргументом вызова | — |
| CS-EE-0008 | вызываемое, не обозначающее объявленную функцию или встроенный метод | — |
| CS-EE-0009 | `ArrowFunction` аргументом объявленной функции | — |
| CS-EE-0010 | цикл в графе вызовов: рекурсия | — |
| CS-EE-0011 | несоответствие числа аргументов | — |
| CS-EE-0019 | изменение обходимой коллекции в теле цикла | — |
| CS-EE-0020 | первый аргумент `Object.assign` — не литерал `{}` | — |
| CS-EE-0021 | обращение к члену пространства имён, отсутствующему в `builtins.json` | — |
| CS-EE-0022 | `toString` или `valueOf` в позиции создания свойства | — |

Первые четыре строки отвергают тексты, которые грамматика ECMA-262 выводит, а
слой ранних ошибок отвергает. Поэтому CS-CONF-0001 говорит о корректном тексте
JavaScript, а не о выводимости грамматикой.

Полные формулировки — в `rules.json`.
