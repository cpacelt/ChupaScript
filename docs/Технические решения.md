# Технические решения

## Исходные данные

- Чтение полей props - наиболее частая операция, должна быть максимально производительной
- Продумать стадии prepare/eval/...
- Парсинг должен быть молниеносным, поэтому предусмотреть вохможность парсить сразу expr для полей, где они ожидаются скипая попытку распарсить стейтменты и тд
- Все изменения переменных должны группироваться, один батч изменений - одна нотификация
- Реализация ast в формате data oriented design (возможно arena)
- Строки не копируем, берем указатели на исходную строку (возможно)
