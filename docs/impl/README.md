# Реализация

Не спецификация языка. Здесь лежит то, что спецификация намеренно не
определяет: как язык встраивается в движок, что требуется от реализации, каким
преобразованием обеспечивается поведение на Web.

Материал перенесён сюда из `docs/spec/` и на определение языка не влияет.
Решения по нему принимаются по ходу реализации, поэтому здесь допустимы
незакрытые вопросы и незавершённые места — в спецификации они недопустимы.

Идентификаторы `CS-CONF-0002`…`CS-CONF-0008`, `CS-EE-0016`, `CS-EE-0017` и
`CS-EE-0018` обозначают здесь те же утверждения, что обозначали в
спецификации. Номера за ними закреплены и другим утверждениям не передаются.
