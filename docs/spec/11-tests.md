# 11. Корпус тестов

> **Статус: план.** Раздел не написан, корпуса нет.

Раздел определит устройство корпуса: форму записи «вход — наблюдаемое
поведение», именование тестов по идентификатору правила, порядок исполнения
интерпретатором и V8.

Роль корпуса: прозаическое утверждение спецификации задаёт правило — что
вычисляется, в каком порядке, что происходит при отказе; точное значение
закрепляет тест — пара «вход — наблюдаемое поведение» на каждый идентификатор.
Прозой значение фиксируется хуже, чем примером.

У всякого `CS-RT-` и `CS-LIB-` должен быть хотя бы один тест; тест называется
идентификатором правила; примеры из документа входят в корпус как его
подмножество.
